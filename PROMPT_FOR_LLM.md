### ОПИСАНИЕ РАЗРАБОТАННОГО ПРИЛОЖЕНИЯ

**Название:** Корпоративный мессенджер (ChatChat)

**Суть:** Полнофункциональное интерактивное веб-приложение для обмена мгновенными сообщениями в режиме реального времени. Система предоставляет пользователям возможность регистрироваться, находить других участников, создавать личные (P2P) диалоги и групповые чаты, отправлять приглашения и обмениваться сообщениями по протоколу WebSocket.

**Функциональные возможности:**
- **Авторизация:** Регистрация и вход с использованием JWT-токенов.
- **Поиск пользователей:** Глобальный поиск по логинам для отправки сообщений или добавления в группу.
- **Личные чаты (Direct Messages):** Создание приватных диалогов один-на-один (RoomType.PRIVATE).
- **Групповые чаты:** Создание комнат (RoomType.GROUP) с несколькими участниками.
- **Управление приглашениями:** Возможность отправить приглашение в группу, а также принять или отклонить входящее приглашение.
- **Модерация групп:** Создатель группы может удалять (kick) участников из чата.
- **Real-time взаимодействие:** Мгновенная доставка сообщений, системных уведомлений (о входе/выходе/удалении участников) посредством Spring WebSocket.
- **Фильтрация и история:** Загрузка истории сообщений при открытии чата с возможностью фильтрации по дате (с/по).
- **Отображение IP:** Дополнительная функция отображения IP-адресов отправителей для аудита.

### ТЕХНОЛОГИЧЕСКИЙ СТЕК

#### Клиентская часть (Frontend)
- **Язык/Среда:** JavaScript (ES6+), HTML5, CSS3
- **Библиотека:** React 18
- **Сборщик:** Vite (быстрая сборка, HMR при разработке)
- **Стилизация:** Чистый CSS с использованием современных спецификаций (Flexbox, Grid)
- **Взаимодействие с API:** Fetch API для REST-запросов и нативный WebSocket API для чата.
- **Архитектура:** Single Page Application (SPA), модульный подход.

#### Серверная часть (Backend)
- **Язык:** Java 21
- **Фреймворк:** Spring Boot 3.3.6
- **Real-Time:** Spring Boot Starter WebSocket
- **Безопасность:** Stateless-архитектура на базе JWT-токенов.
- **ORM:** Spring Data JPA + Hibernate
- **СУБД:** PostgreSQL 15
- **Сборка:** Apache Maven
- **Доп. библиотеки:** Lombok (генерация шаблонного кода), Spring Boot Validation.
- **Порт:** 8080 (REST и WebSocket эндпоинты)

---

### БАЗА ДАННЫХ

**СУБД:** PostgreSQL 15, запускается в Docker-контейнере.  
**Имя БД:** `chatdb`

**Схема (основные таблицы, генерируемые Hibernate DDL):**
1. **users:** хранит id, username (уникальный), password (зашифрованный), token.
2. **chat_rooms:** хранит id, name, type (PRIVATE, GROUP), creator_username.
3. **messages:** хранит id, content, sent_at, sender (username), sender_ip, is_system, room_id.
4. **room_invitations:** хранит id, room_id, invited_username, inviter_username.
5. **room_participants:** таблица связей (многие-ко-многим) между users и chat_rooms.

### REST API И WEBSOCKET

**Base URL:** `http://localhost:8080/api`  
**Формат:** JSON  
**Авторизация:** `Authorization: Bearer <JWT>` для защищённых маршрутов.

**Основные REST-маршруты:**
| Метод | Путь | Описание |
|-------|------|----------|
| POST | `/api/auth/register` | Регистрация пользователя |
| POST | `/api/auth/login` | Авторизация и получение JWT |
| GET | `/api/me` | Получение информации о текущем пользователе |
| GET | `/api/users` | Поиск пользователей (query `?q=`) |
| GET | `/api/rooms` | Получение списка чатов пользователя |
| POST | `/api/rooms` | Создание новой группы |
| POST | `/api/rooms/dm` | Создание или открытие личного чата |
| GET | `/api/rooms/{id}/messages` | Получение истории сообщений с фильтрацией (from, to) |
| POST | `/api/rooms/{id}/kick` | Удаление участника из группы (только для создателя) |
| GET | `/api/invitations` | Просмотр ожидающих приглашений |
| POST | `/api/invitations/{id}/accept` | Принятие приглашения |
| POST | `/api/invitations/{id}/decline`| Отклонение приглашения |

**WebSocket эндпоинт:**
- **URL:** `ws://localhost:8080/ws/chat?token=<JWT>`
- **События:** Отправка JSON-пакетов с `roomId` и `content`. Сервер рассылает сообщения всем активным клиентам комнаты.

---

### DOCKER / РАЗВЁРТЫВАНИЕ

Проект разворачивается с помощью `docker-compose.yml`, который поднимает 3 сервиса:
1. `postgres`: контейнер СУБД (PostgreSQL 15), проброс порта 5432, монтирование volume `postgres_data`.
2. `backend`: Spring Boot приложение. Собирается из `backend/Dockerfile` (двухэтапная сборка Maven + JRE). Зависит от базы данных.
3. `frontend`: React SPA, раздаваемое через Nginx. Собирается из `frontend/Dockerfile` (Node.js сборка + Nginx сервер). Настроен `nginx.conf` для проксирования запросов `/api/` и `/ws/` на backend. Доступ по 80 порту.

Все сервисы объединены в изолированную bridge-сеть `chat_network`.
